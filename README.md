# 加油站排班系統

多站加油站的排班工具。電腦、手機都能用，可以安裝到手機主畫面，離線也能開。

## 功能
- **多站管理**：每站各自設定營業時間（24 小時或自訂）、班別、每班需要人數、員工
- **員工**：正職／計時，計時人員可設定可上班的星期、時段、每週時數上下限
- **排班週期**：每週、每兩週、每月
- **自動排班**：依人力需求排班，遵守一例一休、換班間隔、連續上班、每週 40 小時；🔒 鎖定的預排休假不會被更動
- **勞基法檢查**：第 30、32、34、35、36、37、38、49 條，違法標紅、要注意標橘
- **統計**：工時、加班時數、每月加班累計、國定假日出勤、特休（依到職日週年計算）
- **換班紀錄**：同事換班／代班自動記錄日期、原因
- **匯出**：圖片（傳 LINE）、Excel（CSV）、列印；JSON 備份可在裝置之間搬移、各站合併

## 檔案
| 檔案 | 用途 |
|---|---|
| index.html | 主程式（全部功能都在這裡） |
| manifest.webmanifest、sw.js | 安裝到手機、離線使用 |
| icon*.png、icon.svg | 圖示 |

## 使用方式
- 電腦：直接雙擊 `index.html` 就能用（但要放到網路上才能安裝到手機、離線使用）
- 手機：放到 GitHub Pages 後用手機開網址 → Chrome「加到主畫面」／Safari「分享 › 加入主畫面」

## 注意
- 資料只存在各自裝置的瀏覽器裡，換手機或清除瀏覽器資料前請先「設定 › 匯出備份」
- 國定假日清單請依每年人事行政總處公告核對
- 法規檢查為輔助用途，實際適用以主管機關解釋為準
